Movie Recommender

Find your next film through the movies you already know and the genres you enjoy.

A starting point for movie discovery.

Choosing what to watch starts with a few familiar films. Search the local MovieLens catalog, rate reference movies from one to five, and get a ranked list of suggestions.

The app connects a Python recommendation engine to a framework-free web interface. No account or external movie service is required.

Recommendations you can inspect

Each result includes its genres, audience average, rating count, and the reference films that contributed to the suggestion.

From movie genres to a ranked list.

The engine compares genre profiles, then combines similarity with your ratings and audience response.

  1. Prepare the catalog

    Parse valid title years, clean genre labels, and normalize the source ratings.

  2. Vectorize genres

    TF-IDF turns genre text into numerical vectors that describe each movie.

  3. Find related films

    Cosine similarity finds movies with genre profiles close to your reference films.

  4. Rank candidates

    Combine reference ratings, audience ratings, and similarity position to order the results.

A small, complete browsing experience.

Search and rate

Debounced title search, paginated results, and native radio-based star ratings keep a large catalog manageable.

Keep your selections

Ratings persist in browser local storage, so you can return to your selection without creating an account.

Understand each suggestion

The results connect recommendations to the films you rated and show the audience rating alongside its sample size.

Handle the in-between states

Loading skeletons, error recovery, live status messages, keyboard focus, and reduced-motion support are part of the frontend.

Engineering notes

The implementation choices, delivery workflow, and limits behind the project.

  • Python
  • FastAPI
  • pandas
  • scikit-learn
  • TF-IDF
  • JavaScript
  • Docker
Ranking choices

Catalog browsing uses a Bayesian weighted rating so a single perfect review cannot outrank films with a stronger audience history. Search prioritizes exact title matches, then prefix matches, then substring matches.

The recommendation score is an internal ranking value. It is not shown as a confidence percentage.

Backend and delivery

FastAPI exposes catalog search, recommendations, and a health endpoint. Runtime dependencies are FastAPI, Uvicorn, pandas, and scikit-learn.

Docker packages the processed datasets and frontend, runs as an unprivileged user, and checks application health. CI tests Python and JavaScript, checks generated data, and smoke-tests the container before publishing on pushes to main.

Testing and current limits

The test suite covers routes, frontend assets, API fields, pagination, search ordering, weighted ratings, recommendations, title parsing, and the TF-IDF model.

Recommendations use genre text only, without plots, cast, directors, or semantic embeddings. Ratings stay in the current browser and do not sync across devices. The catalog has no poster provider, and the product is English-only.
